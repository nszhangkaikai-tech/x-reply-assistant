WHY X REPLY

不是没话说，
是评论太多会乱。

做这个插件，起点很简单：评论一多，就容易记混，也容易漏回。谁在回应哪件事、自己之前说过什么、哪些人已经互动、哪些人还没处理，来回切换几次就失去线索。

所以它先把页面上已有的对话背景带进来，再帮你起草；同时把当天读到的评论整理成待办。发帖时，也只在你点击优化的那一刻读取当前“为你推荐”，让优化参考来自此刻的信息流。

少一点记混、漏回和盲目优化，多一点真正接得上的交流。

GOOD TO KNOW

你可能还想知道。

开始之前，把边界说清楚。

现在可以下载使用吗？

可以下载 GitHub 内测版。当前采用手动安装方式，暂不上架 Chrome 商店；下载后请按页面指引加载已解压的扩展程序。

需要自己配置 API 吗？会产生费用吗？

AI 回复和发帖优化需要配置你自己的模型服务。页面模式回复、互动管理与未关注标识不依赖 X API；父帖增强、Lists 与趋势等功能才需要相应的 X 配置。实际费用以各服务商为准。

互动管理能看到所有新评论吗？

不能保证。它不调用 X API，只读取“通知 → 提及”和本人帖子评论页中已经加载的内容。折叠、尚未滚动加载、已删除或其他设备上的操作可能无法自动识别，因此保留手动更新与手动标记。

发帖优化会保存“为你推荐”吗？

不会长期保存。只有在 X 首页“为你推荐”中点击优化时，才按页面顺序读取最多 12 条已加载帖子作为本次参考；不会复制原文，也不代表 X 官方推荐概率。

能读取完整的历史对话吗？

不能保证。页面模式使用当前帖子及已经加载的上文；API 增强模式可尝试补充有限层级的父帖。帖子可见性和接口限制都会影响结果，缺少的信息需要人工核对。

“未关注”是指对方没有关注我吗？

不是。它表示你尚未关注这个账号，不等于对方没有回关你。只有能够确认关系时才显示，不仅限于蓝 V，也不自动关注或取关。

我的数据会发送到哪里？

插件设置、凭证和互动记录保存在当前浏览器本地。生成回复或优化帖子时，相关帖文、上下文、人设，以及本次读取的推荐快照会发送给你配置的模型服务商；只有启用 X API 功能时才请求 X 接口。本介绍页不收集凭证或反馈。

已经安装了内测版，后续如何更新？

在维护页导出安全配置备份，再检查 GitHub 最新版本并下载替换原扩展目录。回到 Chrome 扩展管理页点击“重新加载”即可。
