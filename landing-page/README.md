# X Reply Assistant 静态介绍页

本目录是独立的无构建静态网页，不读取扩展配置，不包含安装包，不调用模型或 X API，不收集用户反馈。

## 本地预览

在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，访问 `http://127.0.0.1:4173`。也可直接打开 `index.html`，浏览器可能限制剪贴板功能，页面会提供手动复制提示。

## 文件

- `index.html`：页面内容、功能示意、使用步骤和常见问题。
- `styles.css`：响应式布局及视觉样式。
- `script.js`：本地示例切换、填入演示框、复制管理页地址。

## 发布方式

- 网站用于产品介绍与安装指引，安装包通过 GitHub Release 发布。
- 暂不上架 Chrome 商店，用户需要在扩展管理页手动加载。
- 网站不读取扩展配置，也不收集密钥或互动数据。

参考 https://bktao.com/x-blue/ 的产品介绍、安装引导、FAQ 内容组织。文案、视觉样式和示意界面独立制作；没有使用参考站的品牌、代码或图片。
